# Мобильное приложение клиента

Отдельное клиентское приложение на Python/Kivy для дипломного проекта фитнес-клуба.

## Возможности

- вход клиента по номеру телефона;
- просмотр активного абонемента;
- просмотр истории посещений;
- просмотр своих записей на групповые тренировки;
- просмотр ближайших тренировок;
- запись на тренировку с проверкой активного абонемента и свободных мест.

## Запуск на ПК для проверки

В текущем окружении запускается PySide6-версия клиентского приложения:

```powershell
.\.venv\Scripts\python.exe mobile_app.py
```

Демо-телефон:

```text
+7 913 100-10-10
```

## Для Android

Для Android/Kivy используется файл `mobile_kivy_app.py`. Для сборки APK обычно используют Buildozer на Linux. В проект добавлен `buildozer.spec`:

```bash
buildozer -v android debug
```

## Важно по окружению

Текущий `.venv` создан на Python 3.14. На Windows для Kivy под Python 3.14 могут отсутствовать готовые зависимости. Для локальной проверки мобильного приложения лучше использовать Python 3.11 или 3.12.
