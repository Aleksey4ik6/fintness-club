Дипломное приложение по теме: **«Разработка программного модуля информационной системы управления фитнес-клубом»**.

Проект реализует именно управленческий модуль информационной системы: учет клиентов, абонементов, посещений, оплат, тренеров, расписания, записей на тренировки и оперативный контроль показателей клуба.

## Быстрый запуск

1. Создайте базу через `database/schema.sql` в MySQL Workbench.
2. Скопируйте `.env.example` в `.env` и укажите пароль MySQL.
3. Установите зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

4. Запустите приложение:

```powershell
.\.venv\Scripts\python.exe init_db.py
```

5. Заполните базу демонстрационными данными:

```powershell
.\.venv\Scripts\python.exe seed_demo.py
```

6. Запустите приложение:

```powershell
.\.venv\Scripts\python.exe main.py
```

Стандартный пользователь после выполнения SQL-схемы:

- логин: `admin`
- пароль: `admin`

## Что уже реализовано

- отдельный раздел управленческого контроля;
- оперативные показатели по клиентам, абонементам, посещаемости, выручке и загрузке тренировок;
- выявление абонементов, требующих внимания администратора;
- контроль загрузки групповых занятий;
- анализ структуры оплат;
- авторизация сотрудника;
- ведение клиентов;
- ведение абонементов;
- автоматическая регистрация посещений;
- проверка активного абонемента при входе клиента;
- автоматическое списание посещения;
- закрытие абонемента, если посещения закончились;
- ведение тренеров, групповых тренировок и оплат;
- отчетные показатели по клиентам, абонементам, посещениям и выручке.
- расписание групповых тренировок;
- запись клиента на тренировку с проверкой свободных мест;
- поиск по таблицам и большим спискам клиентов;
- отображение связанных клиентов, тренеров и абонементов по названию, а не по техническому ID.
- отчеты с фильтром по периоду;
- экспорт отчетов в CSV и Excel XLSX.
